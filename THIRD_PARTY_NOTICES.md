## Sounds

The built-in 808-STYLE and 909-STYLE kits (`firmware/main/core/kits_*.c`, `sdcard/ORBIT/KITS/`) and the bass voice
are synthesized by this project's own code (`tools/kitgen`, `firmware/main/core/acid.cpp`). They contain no Roland
samples or code.

## Bluetooth bridge protocol

`firmware/main/hal/bt_protocol.h` is an independent implementation of the documented UART protocol of the
[Aurora Player](https://github.com/UNIZERSION/aurora-player) "Pico Bluetooth bridge" (same author). No bridge code
is copied.
